# A+ SmartDocs WordPress-Anbindung

Der Ordner `a-plus-smartdocs` kann als WordPress-Erweiterung installiert werden.

## Funktionen

- Einstellbare Portal-Adresse
- Kurzcode `[a_plus_smartdocs_portal]`
- Eintrag „A+ SmartDocs“ im WooCommerce-Kundenkonto
- Deutschsprachige Verknüpfung zu Registrierung und Anmeldung

Die Erweiterung übernimmt bewusst keine Dokumentverarbeitung. Anmeldung, Organisationen, Vorlagen, PDF-Ausgaben und Abonnements werden im getrennten SmartDocs-System betrieben.
