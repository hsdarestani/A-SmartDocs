# Apple App Privacy – A+ SmartDocs

Bundle ID: `de.aplussolution.smartdocs`

## Tracking
- Tracking: **No**
- Data used for third-party advertising: **No**
- Advertising identifier: **Not used**

## Data linked to the user
Depending on the user's actions, the service processes:
- Contact Info: name and email address – account/authentication, team collaboration, support.
- User Content: uploaded PDFs, document edits, generated PDFs – core document editing and export.
- User Content: chat/edit instructions – requested document changes and AI-assisted editing.
- Other User Content / company profile information – organization workspace functionality.
- Usage Data / diagnostics – product operation, security, limits and troubleshooting.
- Purchases / billing status – subscription and account administration where applicable; no card details are collected by the mobile app.

## Third-party processing
When the user asks for AI assistance or the edit target is ambiguous, only the content needed for that request may be processed by the configured AI service provider as a processor. Direct, unambiguous document edits are handled without AI where possible.

## Device access
A+ SmartDocs does not require Contacts, Location, Camera, Microphone or broad Photo Library permissions for the core workflow. Documents are selected through the system file picker and exported through the system share sheet.

## Required URLs
- Privacy Policy: `/datenschutz-app`
- Support URL: `/support`
- Account deletion: available inside Settings and at `/konto-loeschen`

## Review notes
The reviewer should receive a functioning demo account or approved demo mode. Core flow: upload PDF → select/edit document content or use chat → export/share final PDF. Native iOS integration includes the system file picker and native share sheet for generated PDFs.
